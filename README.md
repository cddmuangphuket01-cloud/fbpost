# FB AutoPost
ระบบเว็บสำหรับสร้าง ตั้งเวลา และจัดการโพสต์ Facebook Page

## Run
npm install
npm run dev

เปิด http://localhost:3000

## Features
Dashboard, สร้างโพสต์, ตั้งเวลา, ปฏิทิน, รายการโพสต์ และ Facebook Pages UI

ขณะนี้เป็น Demo Mode และยังไม่ส่งโพสต์จริงไป Facebook

## Facebook จริง
ต้องสร้าง Meta App, OAuth และ Page Access Token ฝั่ง server ก่อน ห้ามใส่ token ใน browser หรือ commit ลง GitHub
